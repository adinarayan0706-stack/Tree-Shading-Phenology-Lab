# 🌳 Tree Shading & Phenology Lab

An interactive 3D web simulation and mathematical calculation engine designed to model botanical growth, seasonal leaf shedding/regrowth, and land shadow footprints for nine indigenous tree species (*Mango, Banana, Amla, Sheesham, Sagvan, Kathal, Jamun, Ber, and Papaya*).

Developed as an academic research project exploring solar geometry and arboricultural microclimate analysis.

---

## ✨ Key Features

- **Interactive 3D Turntable Viewport:** Built with Three.js. Features Fortnite-style 360° mouse drag rotation, orbital camera controls, and smooth scaling from sapling to full maturity.
- **Biometric Growth & Spread Sliders:** Real-time calculation of tree height $H(t)$, crown radius $R(t)$, and species-specific canopy densities.
- **Seasonal Leaf Phenology & Continuous Leaf Fall:** Models annual shedding cycles and leaf regrowth across 365 days, complete with falling leaf particle animations and ground litter accumulation.
- **Solar Geometry & Shading Math:** Synchronously computes Solar Declination ($\delta$), Sun Elevation ($\theta$), Shadow Length ($L = H / \tan\theta$), and Leaf-Adjusted Effective Shaded Land Area ($A_{eff}$).
- **Five Real-Time 2D Analytical Diagrams:** Side profile shadow triangles, top-down compass footprint maps, diurnal hourly curves, annual phenology plots, and a live 9-species comparison bar chart.
- **Student Presentation Notes Modal:** Built-in worked mathematical formulas and a live multi-species comparison table.
- **CSV Data Export:** Export simulation metrics instantly for reporting.
